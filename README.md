# cobtools

cobtools is a modern Python package for astrometry, statistics, kinematics, and IO.

## Features
- Astrometry calculations
- Statistical analysis
- Kinematics utilities
- Input/Output operations

## Installation

```bash
pip install -e .
```

## Usage

```python
from cobtools import astrometry, statistics, kinematics, io

# Example usage
astrometry.example_function()
statistics.example_function()
kinematics.example_function()
io.example_function()
```

## Development

Install development dependencies:

```bash
pip install -e .[dev]
```

Run tests:

```bash
pytest
```
