cobtools.data_models.gaia module

Data model for the Gaia archive.

This module provides data classes for representing and validating Gaia-specific identifiers and related data.

Bases: object

Data class representing a Gaia source ID.

source_id

The Gaia source_id, which can be provided as an integer or a string representing an integer.

Type:

Union[int, str]

data_release

The data release to which the source_id belongs. Defaults to “dr3”.

Type:

str, optional

Raises:

  • ValueError – If source_id is a float or if it cannot be converted to an integer.

  • ValueError – If data_release is not one of the valid options (“dr1”, “dr2”, “edr3”, “dr3”, “dr4”, “dr5”).
